# NEXUS — O Último Refúgio

Protótipo jogável 3D em HTML, CSS, JavaScript e Three.js.

## Executar localmente
Abra o projeto com um servidor local (por exemplo, Live Server no VS Code). O navegador precisa de conexão com a internet para carregar Three.js e as fontes externas.

## Controles
- WASD: mover
- Mouse: olhar (clique em Iniciar Operação)
- Shift: correr
- Espaço: pular
- E: coletar suprimentos próximos
- F: ligar/desligar lanterna

## Deploy no Render
Crie um Static Site conectado a este repositório:
- Build Command: deixe vazio
- Publish Directory: .
- Branch: main

O Render publica o conteúdo estático diretamente, sem servidor backend.
